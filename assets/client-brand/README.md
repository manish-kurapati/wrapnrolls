The PNG artwork comes from the client's `Copy of Final Files.zip`.

Only transparent export padding was trimmed. Patterns were reduced for web delivery. The artwork itself was preserved.

Used on the site:
- Primary logos: header branding in cream and red.
- Secondary logos: compact footer branding.
- Hand submark: homepage story introduction.
- WR submark: homepage closing section, illustration accent, and customisation introduction.
- Illustrated patterns: subtle menu dividers and homepage illustration backgrounds.
- Client colors: red #D13E26, cream #FFEFD2, and yellow #F5B106.

Circular logomarks were deliberately excluded because they contain ESTD and year labels, which the user previously requested to omit. No new promotional claims, menu items, prices, or client copy were introduced.
